# kopineko - iOS Coffee Ordering AppiOS Coffee Ordering App
Project Workshop Swift BNCC

KopiNeko is a lightweight iOS application built with Swift that simulates a coffee ordering experience.  
The project emphasizes simplicity, clarity, and a natural mobile flow using native iOS components.

This app was designed with a minimal interface and intentional interactions, focusing on how users move from browsing a menu to viewing product details in a seamless way.

## Overview

KopiNeko explores how a small, focused mobile application can deliver a clean and intuitive experience without unnecessary complexity. The interface follows modern iOS design principles, prioritizing readability, spacing, and smooth transitions.

## Technology

The application is built natively for iOS using Swift and developed in Xcode. The UI is implemented with UIKit / SwiftUI, following common architectural patterns used in production iOS apps.

## Purpose

This project serves as a hands-on exploration of native iOS development and mobile UI/UX fundamentals. It demonstrates an understanding of structure, navigation, and user-centered design within the Apple ecosystem.

## Future

Planned improvements include expanding the ordering flow, introducing local data persistence, supporting system-wide Dark Mode, and integrating backend services.
